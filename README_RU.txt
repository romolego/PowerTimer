POWER TIMER 2.6.1

Распакуйте архив и откройте PowerTimer.exe. Windows 10/11, .NET Framework 4.8.
Приложение работает от обычного пользователя, без установки пакетов.

В верхней строке выберите «Выключение» или «Гибернация» до запуска.
Постоянный выбор задаётся в настройках в поле «Действие по умолчанию».
Первый из семи интервалов выбран при запуске. Кнопка «Своё время» последняя.
«Запустить» начинает отсчёт. Своё время можно вводить в часах или минутах,
с запятой или точкой. Например, 3,5 часа — это 3 часа 30 минут.
Диапазон — от минуты до 7 суток. Дробная длительность округляется до
ближайшей секунды.

В меню заголовка выберите «Ко времени», чтобы задать дату и время
выключения или гибернации. Введите время или выберите его из списка
с шагом 15 минут. Виджет показывает срок и остаток.
В настройках можно выбрать режим при запуске, скрыть дату и выбрать
начальное время. По умолчанию подставляется текущая минута.
Пауза сохраняет назначенный срок. Если он прошёл, задайте новый.

При активном таймере доступны пауза/продолжение, отмена и виджет.
Виджет показывает время и стрелку; стрелка раскрывает управление вправо.
Двойной щелчок по времени компактного виджета открывает главное окно.
Перетащить виджет можно за область времени. Повторный запуск приложения
возвращает существующее окно/виджет, сохраняя таймер.

Шестерёнка открывает темы, действие по умолчанию, семь интервалов, автозапуск,
поведение при закрытии/сворачивании, размеры и оформление виджета.

Работа в фоне
Приложение должно оставаться запущенным, хотя бы в трее. «Выход» отменяет
таймер. В простое и на паузе нет периодического опроса или записи файлов.
Работающий таймер обновляется примерно раз в секунду. Изменение системных
часов не сокращает оставшуюся длительность. Запрет автоматического сна
действует только при отсчёте; экран может погаснуть. Ручной сон и разряд
батареи этот запрет не предотвращает.

После сбоя будущий таймер восстанавливается на паузе; истёкший снимается.
Если срок прошёл во время сна или задержки обработки дольше 15 секунд,
приложение снимает действие после возобновления.

Выключение и гибернация
При достижении нуля приложение отправляет shutdown.exe /s /t 0 /d p:0:0
для выключения или shutdown.exe /h для гибернации. Гибернация доступна,
если она включена в Windows, и сохраняет сеанс до включения компьютера.
Несохранённые документы могут остановить выключение. Повторных запросов
нет. После передачи запроса Windows отмена внутри приложения уже его
не отзывает. Другие системные таймеры этим приложением не управляются.
Включение компьютера и пробуждение по расписанию не поддерживаются.
Системная политика может запрещать выключение обычному пользователю.

Управление агентом
timerctl.exe status | after 3.5h | hibernate 30m | pause | resume | cancel | widget | tray
Описание API и остальных команд находится в API.txt. API слушает только
127.0.0.1 и требует случайный ключ текущего запуска. Агент должен выполнять
команды на этом компьютере от пользователя приложения.

Данные
%LOCALAPPDATA%\PowerTimer\settings.json — настройки.
%LOCALAPPDATA%\PowerTimer\timer.json — состояние таймера.
%LOCALAPPDATA%\PowerTimer\api.json — адрес, ключ и PID текущего запуска.
%LOCALAPPDATA%\PowerTimer\activity.log — ограниченный локальный журнал.
Не публикуйте api.json. Каталог доступен текущему пользователю, SYSTEM
и администраторам. Приложение не отправляет телеметрию.

Тестирование
PowerTimer.exe --test работает с отдельными данными в PowerTimer-Test.
Выключение и гибернация заменяются записью в журнал. Автозапуск имитируется,
запрет сна не применяется. timerctl.exe --test status обращается к этой копии.
run-tests.ps1 в исходниках запускает полный набор проверок. Python 3.11+
нужен только для интеграционных тестов. Автоматические проверки имитируют
выключение и гибернацию.

Удаление
Отключите автозапуск, выберите «Выход» в трее и удалите папку приложения.
При желании удалите также каталог данных PowerTimer из LocalAppData.
